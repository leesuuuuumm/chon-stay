# 촌스테이 (chon-stay)

한국관광공사 관광 서비스 기획 공모전 — 지정과제 4번(일회성 관광 한계 / 인구감소지역 생활인구 유입) 대응 서비스.

> 실측 이동 데이터를 기반으로 지자체별 핵심 연계 관광 거점을 발굴하고, 체류형 여행 콘텐츠와 연계하여 일회성 관광을 지속가능한 생활인구 유입으로 전환하는 서비스

## 구성

- `backend/` — FastAPI (로컬 SQLite / 운영 AWS RDS)
- `frontend/` — Next.js (웹)

각 디렉터리의 README를 참고해 개별 실행하세요.

## 핵심 기능

1. 체류 매칭 서비스 (관심사-마을 매칭 코스추천)
2. 관계인구 전환 장치 (재방문 유도 알림/쿠폰/커뮤니티)
3. 생활인구 지표 결합 (인구감소 심각도 시각화 및 우선추천)
4. TourAPI 연계 (관광지·축제 결합 코스)
5. 로컬 파트너 연결 (주민-방문자 매칭, 빈집 체험 + 밭 가꾸기)
